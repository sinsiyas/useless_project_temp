project details 
BlinkAI is a computer-vision-based eye-blink monitoring system developed using Python, OpenCV, MediaPipe, and Flask. The system uses a webcam to detect the user’s face and continuously monitors eye movements to identify blinks. It calculates the Eye Aspect Ratio (EAR) to determine whether the eyes are open or closed and counts the number of blinks during a session. The system also calculates the blink rate (blinks per minute) and displays the blink count, elapsed time, and blink rate through a simple web interface. The project can be useful for monitoring eye activity, studying screen-time behaviour, and developing future applications related to driver drowsiness and user alertness.

## Technical Details
BlinkAI is a computer-vision-based blink monitoring system developed using Python, OpenCV, Flask, HTML, CSS, and JavaScript. The system uses the laptop/web camera to continuously capture video frames and detect the user's face and eyes. OpenCV processes the camera frames, identifies eye movements, and detects when the eyes close and open, allowing the system to count blinks. A timer records the monitoring duration, and the blink rate (blinks/minute) is calculated using the total number of detected blinks and elapsed time. The Flask framework is used to connect the Python backend with the web interface, while HTML/CSS/JavaScript provide the dashboard with Blink Count, Time, Blink Rate, Start, and Stop controls. The system can be used for basic eye-blink monitoring and awareness of prolonged screen usage.
